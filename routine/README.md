# routine

예약 작업이 날마다 남기는 분석 결과입니다. 나중에 대화에서 이 폴더를 읽어 여러 날을 종합할 때 씁니다.
날짜 폴더(YYYYMMDD)는 각 예약 작업이 직접 만들고, 같은 날 다시 실행되면 새 결과로 덮어씁니다.

## option_market/ — 예약 작업 "옵션 시장 분석" (화~토 아침)

- 날짜 폴더: 분석 기준일(미국 거래일). 그날 마감 호가를 직전 거래일과 견준 결과입니다.
- `report.md`: 사용자에게 보낸 보고서 본문
- `sentiment.json`: `option_sentiment.py --out-json` 결과. SPX·VIX·GLD 옵션 지표와 VIX·VVIX·GVZ 방식 분해(SPX 분해는 Cboe 공식값)
- `gex.json`: `gex.py --out-json` 결과. SPX 감마 노출(GEX)
- `output.txt`: 두 스크립트의 출력 원문
- 그림은 저장하지 않습니다. 분석에 실패했거나 미국 휴장으로 새 자료가 없는 날은 폴더가 없습니다.

## macro_hypothesis/ — 예약 작업 "매크로 가설 일일 점검: 미국 국채(장기금리 고점 통과)" (매일 아침)

- 날짜 폴더: 새 미국 종가가 있는 날은 그 미국 거래일, 없는 날(일·월요일 아침, 미국 휴장)은 실행 시점의 미국 동부 날짜입니다.
- `report.md`: 사용자에게 보낸 보고서 본문
- `data.json`: 보고서의 핵심 수치와 판정. 10년 금리와 폐기선(5.31%)·확인선(4.84%)까지 거리, IEF·TLT 누적 수익률, 30년-10년 금리 차, 브렌트유, 원/달러, 주가 급락일의 금리 방향, 상태, 확신 수준, 달라진 전제, 다가오는 일정, 출처
- 금리는 % 단위, 금리 변화와 거리는 %p, 수익률·변화율은 %입니다. 없는 값은 `null`입니다.
